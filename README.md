# 🎹 Registro Lezioni di Pianoforte

Un'applicazione desktop per Windows pensata per organizzare, annotare e monitorare i progressi delle lezioni di pianoforte.

## 📥 Come scaricare e avviare il programma (Windows)
Non è necessario installare Python o altri programmi aggiuntivi:

1. Vai nella sezione **[Releases](../../releases)** (oppure usa il link diretto fornito).
2. Scarica il file **`Registro_Lezioni_Pianoforte.exe`**.
3. Fai doppio clic sul file scaricato per avviare il programma. *(Nota: se Windows mostra un avviso di sicurezza "SmartScreen", clicca su "Ulteriori informazioni" e poi su "Esegui comunque").*
